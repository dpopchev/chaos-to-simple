# Stacey matrix: agreement on the What, certainty on the How

## Two axes, four zones {paths=64}

![](build/02-stacey/stacey.png){height=80%}

::: notes
Agreement on the What: do we agree what the system should do? Certainty on the How: do we
know how to build it? Simple when both, complicated when one, complex when neither, chaos
when we cannot even count the questions.
:::

## Bits on the map

| zone | what we know about the bits |
|---|---|
| chaos | we do not know how many there are |
| complex | we know the count, we agree on nothing, we are sure of nothing |
| complicated on the What | the How is settled, the rules are not |
| complicated on the How | the rules are settled, the code is not |
| simple | both settled: every bit has a name and a home |

## The route of this talk

- 01: six ifs, unknown count: chaos
- 03: nine bits, 512 paths: complex
- 04: one language, bounded contexts: the What agreed
- 05: decoupling, CQS: the How settled
- 06: core and shell, 72 paths: simple

::: notes
A thinking tool, not a law. The matrix tells us which kind of work comes next, not how
to do it. The next four sections are the four moves.
:::
