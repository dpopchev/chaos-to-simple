## Action
Add 00-frontmatter/filters/story.lua, listed in 00-frontmatter/defaults.yaml before diffs.lua. It renders a code block carrying both classes diff and python as: line 1 (the heading) as \storyhead{<escaped text>}; the body highlighted as Python through pandoc's own highlighter (pandoc.write of a python CodeBlock to latex, style tango), each body line's first character stripped before highlighting and that character choosing the line's background: + \diffaddbg, - \diffdelbg, space (a scope row) \diffscope; the frame heading ahead of it gets the fragile class as diffs.lua does. A Div with class request becomes \begin{request} ... \end{request}. In 00-frontmatter/preamble.tex define the colours shadecolor (the code shade), requestbg, headbg, addbg, delbg, the macros \storyhead (a tcbox across the line in headbg), \diffaddbg / \diffdelbg / \diffscope (a \colorbox over \makebox[\dimexpr\linewidth-2\fboxsep][l]) and the request tcolorbox.
