## Hypothesis
Can one named font draw the nine actor icons both in lualatex and in matplotlib, so every actor renders as a pictogram rather than a labelled box?

## Outcome
Given the fonts this machine has, When make spike-fa, Then build/spike/fa-probe.pdf and build/spike/fa-probe.png show the nine actor icons from one named font and 00-frontmatter/README.md records that font as the Decision.

## Findings
- 2026-11-02 fact: lualatex draws all nine actor icons with no Missing character via fontawesome5 (its own FA5 OTF), fontspec Font Awesome 7 Free Solid and fontspec Hack Nerd Font -> both installed fonts serve lualatex
- 2026-11-02 fact: matplotlib draws all nine actor icons from Font Awesome 7 Free-Solid-900.otf and from HackNerdFont-Regular.ttf, loaded by fc-list path -> one named font serves both renderers; FA7 Free is the one fc-list finds first
- 2026-11-02 fact: otf-font-awesome is Font Awesome 7 Free, not 6, icons in its Solid face; Nerd Fonts moves warehouse, store, layer-group to ED92, EE17, EEA8 -> scripts/utils/icons.py keeps a codepoint per font, read with fontTools

## Decisions
- 2026-11-02: Font Awesome 7 Free Solid serves both renderers: fontspec in lualatex, its fc-list path in matplotlib; ICONS in scripts/utils/icons.py maps a name to its codepoint; fontawesome5 is the second choice, Hack Nerd Font the third, a labelled box the fallback if fc-list finds none
